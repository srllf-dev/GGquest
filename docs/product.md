# GGquest — Product

## Visão

O GGquest é uma plataforma para registrar e gamificar
a jornada do usuário pelos games.

> A Steam registra o que você joga.
> O GGquest registra sua jornada como jogador.

## Principais sistemas

- Biblioteca
- Ranking
- Quests
- XP e níveis
- Conquistas
- Perfil
- Página individual do jogo

## Biblioteca

O usuário poderá organizar seus jogos por status:

- 🔵 Quero consumir
- 🟡 Consumindo
- 🟢 Concluído
- 🔴 Abandonado

## Ranking

A nota define a posição do jogo.

Em caso de empate, o usuário poderá definir
qual jogo prefere que fique acima.

## Quests

As quests funcionam como missões de RPG.

Cada quest possui:

- dificuldade
- objetivo
- progresso
- XP
- recompensa

Também existirão quests secretas.

## Conclusão

Um jogo pode ser considerado concluído quando:

- a história principal foi finalizada; ou
- o usuário atingiu a condição definida para conclusão.

Um jogo com 100% das conquistas recebe um emblema especial.

## Perfil

O perfil apresenta a identidade gamer do usuário:

- nome
- avatar
- jogo favorito
- gênero favorito
- nota média
- nível
- XP
- jogos
- Top 3
- conquistas
- estatísticas
